## 3. 关键文件与初步检查结果

### Electron 主菜单

文件：`packages/main/menu.ts`

可见文字包括菜单标签、系统消息框标题/正文/详情、文件过滤器名称。需要区分显示标签与内部菜单 role、accelerator、ID、IPC 通道。

### 通用对话框

文件：`packages/eez-studio-ui/dialog.tsx`

默认按钮文字包含 `Cancel`，并支持业务侧传入 `okButtonText`、`cancelButtonText`。应在统一翻译 API 中处理默认值，同时不覆盖业务自定义文字。

文件：`packages/eez-studio-ui/generic-dialog.tsx`

字段模型支持 `displayName`、`enumItems`、`formText`、`validators` 等。它会把字段定义动态渲染成表单，因此字段名和枚举标签不能只通过扫描 JSX 静态字符串来处理。

### 通知

文件：`packages/eez-studio-ui/notification.tsx`

通知容器提供 info、success、warn、error 等展示函数，接收调用方传入的消息内容。需要继续盘点调用点，才能覆盖实际提示文字。

### 表单校验

文件：`packages/eez-studio-shared/validation.ts`

已发现英文校验消息：
- `Invalid value.`
- `Please fill out this field.`
- `Please enter value between ${min} and ${max}.`
- `Please enter value greater than or equal to ${min}.`
- `Please enter value between (not included) ${min} and ${max}.`
- `Please enter value greater than ${min}.`
- `This field has no unique value.`
- `Character "${char}" is not allowed.`
- `Invalid file name`

这些信息必须保留参数替换行为，不能在翻译时丢失范围值或非法字符。

### 区域设置

文件：`packages/eez-studio-shared/i10n.ts`

包含 `zh-CN`、`zh-TW` locale 代码，但当前可见导出集中在 locale、日期格式和时间格式设置。它不是 UI 字符串翻译目录。

## 4. 推荐实施顺序

1. 统一翻译 API 与资源文件格式，先支持主进程和渲染进程。
2. 翻译 Electron 主菜单与系统消息框。
3. 翻译通用对话框、默认按钮、表单校验错误。
4. 迁移首页、通用 UI、通知调用点。
5. 迁移项目编辑器的控件/属性/事件/流程相关文字。
6. 迁移仪器模块、笔记本、帮助和组件文档。
7. 自动扫描遗漏的英文可见字符串，并进行运行时回归测试。

## 5. 不应翻译的内容

- TypeScript/JavaScript 变量、函数、类、接口和枚举标识符；
- Electron 菜单 role、accelerator、菜单 ID、IPC 通道；
- LVGL API、SCPI 命令、协议字段、设备型号；
- 项目文件格式、JSON key、内部序列化值；
- 生成代码、用户输入和用户项目中的文本；
- 第三方库接口与许可证原文。

## 6. 完成标准

不能以“英文字符串替换数量”作为唯一指标。每类界面入口必须满足：
- 翻译完整且术语统一；
- 参数、快捷键和动态值正常；
- 无空白标签、未翻译错误或占位符泄漏；
- 中文布局无严重截断；
- 项目打开、编辑、保存、构建和仪器连接等核心功能不回归。
