# EEZ Studio 简体中文术语表

本术语表用于统一软件界面翻译。遇到新术语时先检查本表，再决定是否新增。技术标识符、代码符号和协议字段不因术语表而修改。

## 翻译约定

- 菜单、按钮和标签优先使用简短、明确的中文。
- 错误信息先说明发生了什么，再说明原因或处理建议；不得删掉原始错误细节。
- 动态消息中的路径、变量、数值和占位符必须原样保留。
- API、代码符号、枚举内部值、文件扩展名和协议字段保持英文。
- 同一英文词在不同上下文含义不同时，允许采用不同译法，但必须在术语表备注上下文。
